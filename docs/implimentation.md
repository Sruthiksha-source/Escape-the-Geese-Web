## Implementation overview

*Escape the Geese* is developed in Java 17 using the LibGDX framework. The implementation is based on the architecture described in Arch1.pdf, which separates the presentation, game logic and supporting components.

The implementation report records the libraries and assets used, their licences, and any requirements that have not been fully implemented.
